# Feature Acceptance Criteria

## Standard Checklist

Every feature must have:

1. **User Story**: Clear who/what/why
2. **Success Metrics**: How we measure success
3. **Edge Cases**: What could go wrong
4. **Mobile Design**: How it works on small screens
5. **Offline Behavior**: What works offline
6. **Error States**: What user sees on failure
7. **Test Cases**: Automated and manual tests
8. **Documentation**: User guide and API docs
