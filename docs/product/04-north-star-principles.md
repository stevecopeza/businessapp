# BusinessApp — North-Star Principles

## What We Will Build

- Tools that make work clearer
- Systems that adapt to different trades
- Features that support quoting first
- Simple flows that work in the field
- Professional outcomes without bureaucracy

## What We Will Not Build

- Full accounting systems
- Enterprise workflows
- Over-automated processes
- Rigid product catalogues
- Features that add cognitive load

## Guiding Beliefs

- Clarity beats completeness
- Agreement beats documentation
- Flexibility beats configuration overload
- Focus beats feature count

Every decision should reinforce these principles.
