# BusinessApp — User Archetypes

## Owner-Operator
- Creates and approves quotes
- Cares about professionalism and trust
- Wants minimal admin overhead

## Staff Member
- Creates quotes in the field
- Needs speed and clarity
- May not set pricing rules

## Customer
- Wants to understand what’s included
- Wants transparency and reassurance
- Does not want another login or system

Each archetype has different needs, but all interact with the same quote.
